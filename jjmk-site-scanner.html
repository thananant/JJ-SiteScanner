พิมพ์ช่องไหนก็ได้แล้วแตะเลือกจากรายการ — เลือกเขตแล้วรายการแขวงจะเด้งให้เลือกต่อทันที ระบบเติมครบทุกช่องอัตโนมัติ (ครอบคลุม กทม. ครบ 50 เขต 180 แขวง + นนทบุรี ปทุมธานี สมุทรปราการ สมุทรสาคร นครปฐม ระดับตำบล • จังหวัดอื่นพิมพ์เองได้ตามปกติ)
ติดตั้งโหมดคลาวด์แล้ว? ช่องนี้เว้นว่างได้เลย — แอพเรียก AI ผ่าน Supabase โดย key เก็บเป็น Secret ฝั่งเซิร์ฟเวอร์ ทุกเครื่องใช้ได้ทันทีไม่ต้องตั้งค่า
วิธีเอา key (กรณีใช้แบบใส่ key ในเครื่อง): เข้า platform.claude.com → สมัคร/ล็อกอิน Console (คนละบัญชีกับแอป Claude — แพ็กเกจ Pro/Max ใช้แทนไม่ได้) → เมนู Billing เติมเครดิต → เมนู API Keys → Create Key → คัดลอกทั้งเส้น (ขึ้นต้น sk-ant-) มาวางช่องบนแล้วสแกนได้เลย
• เปิดผ่านหน้า Claude โดยตรง — ไม่ต้องใส่ key ระบบจัดการให้
• เปิดบน GitHub Pages / เปิดไฟล์เอง — ต้องใส่ key เสมอ (key เก็บในเครื่องนี้เท่านั้น และส่งตรงหา Anthropic ที่เดียว)
• ค่าใช้จ่ายต่อสแกน: ค้นเว็บสูงสุด 10 ครั้ง + โทเคน รวมราวหลักบาทถึง ~10 บาท ใช้เวลา ~1–2 นาที
URL + publishable key ตั้งค่ามาให้ครบแล้ว (โปรเจกต์ jjmk-stock) — ทำครั้งแรกครั้งเดียว: รันไฟล์ jj3-supabase-setup.sql ใน SQL Editor แล้วแอพจะซิงก์อัตโนมัติทุกเครื่องเอง • ช่องนี้แก้เฉพาะตอนย้ายโปรเจกต์ • ห้ามใช้ sb_secret_ ในแอพนี้เด็ดขาด

• ปุ่มสแกนทุกโซน: ไล่ค้นครบ 20 โซนอัตโนมัติใน ~2–3 นาที (~60 ครั้ง/รอบ จากโควตาฟรี ~5,000 ครั้ง/เดือน) กดซ้ำเพื่อหยุดกลางทางได้ — แนะนำรันซ้ำสัปดาห์ละครั้งเพื่อให้ระบบคำนวณอัตรารีวิวเพิ่ม

• ข้อมูลทั้งสองทางถูกรวมเข้าชุดเดียว จำไว้ในเครื่อง แตะหมุด/รายการเพื่อดูรายละเอียดและเปิดใน Google Maps

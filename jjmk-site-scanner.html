พื้นที่ที่จะสแกน

พิมพ์ช่องไหนก็ได้แล้วแตะเลือกจากรายการ — เลือกเขตแล้วรายการแขวงจะเด้งให้เลือกต่อทันที ระบบเติมครบทุกช่องอัตโนมัติ (ครอบคลุม กทม. ครบ 50 เขต 180 แขวง + นนทบุรี ปทุมธานี สมุทรปราการ สมุทรสาคร นครปฐม ระดับตำบล • จังหวัดอื่นพิมพ์เองได้ตามปกติ)
วิธีเอา key (ทำครั้งเดียว): เข้า platform.claude.com → สมัคร/ล็อกอิน Console (คนละบัญชีกับแอป Claude — แพ็กเกจ Pro/Max ใช้แทนไม่ได้) → เมนู Billing เติมเครดิต → เมนู API Keys → Create Key → คัดลอกทั้งเส้น (ขึ้นต้น sk-ant-) มาวางช่องบนแล้วสแกนได้เลย
• เปิดผ่านหน้า Claude โดยตรง — ไม่ต้องใส่ key ระบบจัดการให้
• เปิดบน GitHub Pages / เปิดไฟล์เอง — ต้องใส่ key เสมอ (key เก็บในเครื่องนี้เท่านั้น และส่งตรงหา Anthropic ที่เดียว)
• ค่าใช้จ่ายต่อสแกน: ค้นเว็บสูงสุด 10 ครั้ง + โทเคน รวมราวหลักบาทถึง ~10 บาท ใช้เวลา ~1–2 นาที
ก่อนเชื่อมครั้งแรก: รันไฟล์ jj3-supabase-setup.sql ใน Supabase SQL Editor หนึ่งครั้ง (idempotent รันซ้ำได้) แล้วเอา URL + anon key จาก Project Settings › API มาวาง

แผนที่ร้านคิวยาว กทม.+ปริมณฑล

ร้านคิวยาว/คนเยอะ สาขาจริงใจ (2 สาขา) ทำเลที่สแกนแล้ว
• ปุ่ม AI: ใช้ Anthropic key เดิม ไปกวาดรีวิว Google Maps + บทความ หาร้านที่คนพูดว่า "คิวยาว คิวเยอะ รอนาน คนเยอะ" ทั่ว กทม.+ปริมณฑล (~1–2 นาที)
• ปุ่ม Google: ยิง Places API ค้นคำว่าคิวยาว/รอคิวในโซนที่เลือกแบบสด — ต้องมี Google Maps API key (สร้างที่ console.cloud.google.com เปิดใช้ Maps JavaScript API + Places API (New) มีโควตาฟรีรายเดือนพอใช้ส่วนตัว แนะนำตั้ง restriction โดเมน + budget alert)
• ข้อมูลทั้งสองทางถูกรวมเข้าชุดเดียว จำไว้ในเครื่อง แตะหมุด/รายการเพื่อดูรายละเอียดและเปิดใน Google Maps
